# Reporte de suelo · Blum

Página para generar el reporte de **% Humedad y Conductividad Eléctrica** a partir del export de mediciones de BLUM (hoja «Meter»).

1. Abre la página y sube el Excel exportado desde BLUM.
2. El encabezado, los gráficos, las tablas y las observaciones se completan solos con los datos.
3. Haz clic en **Descargar PDF**.

El Excel se procesa en el navegador de quien lo sube; no se envía a ningún servidor.

# Dashboard BLUM

Página para revisar y descargar en PDF los reportes de campo a partir del export de mediciones de BLUM (hoja «Meter»): **Caseta**, **Terreno** (presión de válvulas y aforos por bloque de riego), **Suelo** (% humedad, CE y otras mediciones) y **Ósmosis inversa**.

1. Abre la página y sube el Excel exportado desde BLUM en cualquier pestaña: se reparte solo entre las pestañas.
2. Filtra por campo o equipo, fecha (calendario) y horario.
3. Los gráficos, tablas y observaciones se completan solos con los datos. Haz clic en **Descargar PDF**.

El Excel se procesa en el navegador de quien lo sube; no se envía a ningún servidor.
